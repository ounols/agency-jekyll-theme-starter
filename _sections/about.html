프로그래머 이진영입니다.

C++ 엔진을 직접 만들며 익힌 구조와 렌더링 지식으로 게임의 구조 문제와 성능 문제를 풀어 왔습니다.
2020년부터 Unity와 Unreal 실무 프로젝트에서 콘텐츠, 렌더링, 최적화를 맡았습니다.

자체 엔진 C++로 2017년부터 혼자 개발하며 렌더링, 리플렉션, 에디터까지 구현했습니다. GitHub 스타 103개를 받았습니다. Unreal C++ 전투기 워게임 시뮬레이터의 에디터, 시뮬레이션, 직렬화 프레임워크를 맡았습니다. 최적화 3D 오픈월드를 갤럭시 S10 모바일 브라우저에서 RAM 700MB, 50fps로 구동했습니다. 팀 리드 11인 프로젝트에서 파트장으로 프로파일링과 구조 리팩토링을 이끌었습니다. 라이브 서비스 랜덤 기사단의 Google Play 출시와 라이브 운영 시스템을 개발했습니다.
